## Our Security Philosophy: "Zero Trust"

Shadow PDF is built on a zero-leakage architecture. Our security model is simple: We cannot steal what we never receive.

- 100% Client-Side: All processing happens in your browser's memory using JavaScript.

- No Analytics: We do not use Google Analytics, cookies, or trackers.

- No Network Calls: Once the page is loaded, the tool functions without sending a single packet to any external server.
